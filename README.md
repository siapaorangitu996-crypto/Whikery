# Notosan Landing Page

A high-fidelity, interactive landing page for **Notosan (Noto Nature Park)**. Built with modern web technologies for performance and fluid animations.

## Tech Stack
- **Framework:** [Next.js 15 (App Router)](https://nextjs.org/)
- **UI & Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Typography:** Inter (Sans) & Playfair Display (Serif)

## Key Features
- **Responsive Design:** Optimized for Desktop, Tablet, and Mobile.
- **High Performance:** Server-side rendering and optimized image assets.
- **Fluid Interactions:** Smooth entrance animations and hover effects using Framer Motion.
- **Modern UI:** Clean, nature-inspired design with focus on typography.

## Getting Started

1.  Clone the repository.
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run the development server:
    ```bash
    npm run dev
    ```
4.  Open [http://localhost:3000](http://localhost:3000) in your browser.

## Project Structure
- `src/app/`: Next.js App Router pages and layouts.
- `src/components/`: Reusable React components (Navbar, Hero, etc.).
- `public/`: Static assets including background images and icons.
